<summary>About this step</summary>

Node runs development tools; TypeScript checks the model before JavaScript runs; React turns the model into a page. Vite serves the exported app. The preview already contains three shipment records so you can focus on one change.

An interface describes each record. A string union restricts a field to a small set of allowed values. Add the required priority field, update all records, then render it. A type error while only some records have been updated is useful feedback; finish the model before checking the preview.

The sandbox uses its own pinned dependencies, separate from this documentation website. No package installation is needed for this step.
