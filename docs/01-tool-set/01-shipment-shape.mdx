Node runs development tools, TypeScript checks the shape of data, and React displays it. Vite serves the exported app. Start with three records in `/shipments.ts`; no installation is needed in the browser. An [interface](https://www.typescriptlang.org/docs/handbook/2/objects.html) describes the fields each record must have; a union limits the allowed values.

1. In `/shipments.ts`, replace the TODO inside `Shipment` with `priority: 'standard' | 'express';`. The field is required, so every `Shipment` must supply it.
2. In the array below, add `priority: 'express'` to S-101 and `priority: 'standard'` to each other object. Commas separate object properties. Until all three are updated, a type checker can report missing fields.
3. In `/App.tsx`, replace the TODO inside the list item with `<span> · {shipment.priority}</span>`. JSX braces evaluate the property for each mapped record. The preview should show all three rows with their priority.

If a value is rejected, check its spelling and quotes against the union; `Standard` is a different string. In a local export these editor files live under `src/`.
