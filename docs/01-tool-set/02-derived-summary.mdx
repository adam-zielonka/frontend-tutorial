Continue with the typed shipments from the previous solution. The list is the source of truth: derive the total pallets and ready count from it each time the component renders.

Use `reduce` to accumulate quantities and `filter(...).length` to count matching records. Render the summary above the same list so the numbers and rows describe the same data. No state or effect is necessary for these fixed records.
