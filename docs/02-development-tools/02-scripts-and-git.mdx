Continue from the two enabled settings. Finish the practice script values and check the preview. A JavaScript object containing command strings cannot execute them or change Git.

For the real workflow, use Node 24 in an exported project outside the tutorial website. Run `pnpm install`, `pnpm exec tsc --noEmit`, and `pnpm dev`. The export already supplies a dev script. To use `pnpm typecheck`, add `"typecheck": "tsc --noEmit"` to its actual `package.json` scripts. Opening the printed Vite address shows your local app; Ctrl+C stops the server. The host flag makes the development server listen on all network interfaces.

In a new local folder run `git init`, then use `git status` and `git diff` to review your changes before staging source files and making a commit. Keep dependencies and secrets out of commits. Browser developer tools offer a separate view: Console shows errors and Network shows file requests.
