<summary>About this step</summary>

The open file is a typed practice model. Setting `formatOnSave` and `strict` changes the checklist in the preview, but does not change your editor or the running sandbox's compiler settings.

After the practice, open the exported project in VS Code. Enable `editor.formatOnSave` in your editor settings and choose a formatter if none is configured. Inspect `compilerOptions.strict` in the actual `tsconfig.json`; the export already enables it. Formatting improves consistency, while strict checking helps catch type mistakes. These are separate tools.
