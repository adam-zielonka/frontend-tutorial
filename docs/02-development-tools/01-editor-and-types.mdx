The starter is a checklist model, not the configuration of your editor or compiler. `/App.tsx` reads its values; `/project.ts` holds them. Formatting and type checking solve different problems: formatting makes layout consistent, while [strict](https://www.typescriptlang.org/tsconfig/strict.html) enables stricter compiler checks.

1. In `/project.ts`, find `project` below the interface and change `formatOnSave: false` to `formatOnSave: true`.
2. Change `strict: false` to `strict: true`. These are boolean values, not strings: omit quotation marks. The preview should show 2 / 4 settings ready; script settings are for the next step.
3. For a real local project, export it and open its folder in VS Code. Open Settings, search for `editor.formatOnSave`, enable it and select a formatter if needed. Inspect `compilerOptions.strict` in the exported `tsconfig.json` (already enabled). See [VS Code settings](https://code.visualstudio.com/docs/configure/settings).

If the checklist does not change, edit the values in the object, not the `boolean` declarations in the interface. The editor model does not actually change VS Code.

## Check your work

Confirm only Format on save and Strict types say Ready. In your local project, verify the actual setting and `tsconfig.json` separately. Next you will model scripts and run real commands in a terminal.
