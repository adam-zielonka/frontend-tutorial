# Course help

Each embedded exercise opens a prepared starter. Your edits stay in that lesson’s browser draft. Download work you want to keep: clearing storage, changing devices or a starter update can make the draft unavailable.

Use the hints or compare the read-only **Solution**, then return to **Your code** to continue editing.

**Download my files** saves a JSON file containing your edited lesson files. Choose **Work locally** for the matching clone, installation, and import commands. Importing replaces that local lesson project's exercise files; use a separate clone and the matching lesson download. A tagged online editor opens its checkpoint, not your browser edits. Virtual `/App.tsx` and similar source paths correspond to files under `src/` in the local project; public assets live under `public/`.

Refresh the preview to restart the example with your source edits and recreate models that survived a hot update. If the embedded preview cannot connect, use **Work locally** or the online editor. Do not enter private data in the examples.

## Running tests

In chapter 6, **Run tests** sends the current editor files to a temporary StackBlitz workspace running the real, pinned Vitest version. The first run installs dependencies; later runs update those files and rerun the tests. The workspace is not saved to a StackBlitz account unless you choose to fork it there.

Embedded WebContainers are supported in Chromium browsers. On Safari (including iPhone) and Firefox, **Run tests** opens the same files in a separate tab. If an embedded workspace cannot connect, **Open these tests in a new tab** keeps your edits; **Work locally** remains available for running `pnpm test:run` after importing them. See [StackBlitz browser support](https://developer.stackblitz.com/platform/webcontainers/browser-support) and [Vitest reporters](https://vitest.dev/guide/reporters).

The report shows the last run. Edit **Your code** and run again to test a change. Edits made in StackBlitz stay there. Running **Solution** tests its separate, read-only snapshot.
