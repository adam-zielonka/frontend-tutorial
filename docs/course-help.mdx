# Course help

Each lesson opens a prepared checkpoint. The next lesson starts from its prepared version of the previous solution; your edits are not copied forward. Your draft is saved separately for each lesson in this browser when storage is available. Clearing browser storage, using another device, or a changed lesson starter can make a saved draft unavailable, so download a copy you want to keep.

**Solution** is read-only and does not replace **Your code**. Use hints and compare the solution, then return to your code to make changes.

**Download my files** saves a JSON file containing your edited lesson files. Choose **Work locally** for the matching clone, installation, and import commands. Importing replaces that local lesson project's exercise files; use a separate clone and the matching lesson download. A tagged online editor opens its checkpoint, not your browser edits. Virtual `/App.tsx` and similar source paths correspond to files under `src/` in the local project; public assets live under `public/`.

A preview refresh restarts the running example and retains source edits. It can recreate models whose old instances survived a hot update, but it does not transfer your edits to another lesson. If the embedded preview cannot connect, use **Work locally** or the online editor. Do not enter private data in the examples.
