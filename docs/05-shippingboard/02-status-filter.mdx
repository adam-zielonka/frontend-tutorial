This starter includes the working view buttons from 5.1. The status selector already stores a typed `filter`, but the table still reads every loading. Derive the visible rows during render so the table and its count always agree, without deleting records or storing a second array in state.

## Derive the visible records

In `/App.tsx`, replace `const visible = loadings;` with:

```tsx title="/App.tsx"
const visible = loadings.filter(item => filter === 'all' || item.status === filter);
```

The first condition accepts every record for All; the second accepts an exact status match. The selector already calls `setFilter`, and both the table and live count already read `visible`, so no other wiring is needed. `/data.ts` remains the fixed source.
