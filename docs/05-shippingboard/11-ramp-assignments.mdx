The card now looks right, but every ramp shows the same loading. Each loading already knows which ramp it belongs to. You can use that reference to answer the question from the other direction: which loadings belong on this ramp?

Continue in your local checkout or online session from [5.5](./05-original-workspace.mdx), with the previous step’s edits.

## Make the change

Replace `src/store/Ramp.ts` with this complete intermediate model:

```ts title="src/store/Ramp.ts — assigned loadings"
import { makeAutoObservable } from "mobx";
import { Loading } from "./Loading";
import { store } from "./Store";

export class Ramp {
  constructor(
    public id: string,
    public description: string,
  ) {
    makeAutoObservable(this);
  }

  get loadings(): Loading[] {
    return store.loadings.filter(loading => loading.ramp === this);
  }
}
```

Take loading `0007703`. When the app reads its data, `FromResponse.ramp` in `src/api/parse.ts` looks up C in `store.ramps`. It puts that exact ramp object in `loading.ramp`. Inside C’s getter, `this` is the same object, so `loading.ramp === this` includes `0007703`. Inside D’s getter, that comparison is false.

Choosing a ramp in the dialog calls `setRamp` and changes that one reference. Clearing the ramp calls `clearRamp` and sets the reference to `undefined`, so the loading appears only in the table. All assigned IDs in this exercise refer to known ramps.

With `makeAutoObservable`, MobX treats the getter as a [computed value](https://mobx.js.org/computeds.html). When the assignment changes, components that read the getter can show the new list. You only have to update the loading itself.

Replace `src/components/RampBox.tsx` completely, removing the temporary `store` import and single-loading example:

```tsx title="src/components/RampBox.tsx — assigned cards"
import { Card, Elevation } from "@blueprintjs/core";
import { observer } from "mobx-react-lite";
import { Ramp } from "../store/Ramp";
import { LoadingBox } from "./LoadingBox";
import "./Ramp.scss";

export const RampBox = observer(({ ramp }: { ramp: Ramp }) => {
  return <Card className="Ramp" elevation={Elevation.ONE}>
    <header>{ramp.description}</header>
    <main>
      {ramp.loadings.map(loading =>
        <LoadingBox key={loading.id} loading={loading} />
      )}
    </main>
  </Card>;
});
```
