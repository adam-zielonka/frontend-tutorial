The board starts with the same three loading records and three ramps used throughout this chapter. React state holds the selected view; the records remain fixed support data in `data.ts`.

The two sections are already selected by a conditional expression. Wire the navigation handlers so one selects `loadings` and the other `ramps`. `aria-pressed` exposes the active choice. The ramp view is a scaffold that later lessons will fill in; it does not yet show assignments.
