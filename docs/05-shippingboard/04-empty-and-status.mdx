An empty list needs an explanation. R3 is genuinely available, while R2 can look empty merely because its loading does not match the selected filter. Render different messages for those cases.

Derive ramp status from **all** assignments, so selecting Done cannot make a busy ramp appear complete or available. Check for zero assignments before `every`, then check completion, active loading, and waiting in that order. With the supplied fixture the statuses are Waiting, Loading, and Available. To exercise Complete, temporarily mark both R1 records done in `data.ts`, then restore the fixture.
