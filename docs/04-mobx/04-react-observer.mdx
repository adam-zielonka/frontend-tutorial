<summary>About this step</summary>

**Setup from step 3:** the temporary React value snapshot and its bridge handlers are removed. `Counter` now reads the completed store directly and calls its bound actions. Its initial zero still renders, but clicks do not refresh the display: the missing subscription is this exercise.

Wrap `Counter` with `observer`. MobX records observable reads made during that component's render and schedules updates when those values change. Keep `counter.value` inside that render; making a class observable alone does not subscribe React. `App` only owns a stable store reference at this stage.

After completing the wrapper, all five controls should update immediately without any extra `setValue` call.
