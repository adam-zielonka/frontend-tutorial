This guided continuation uses your completed local **4.12 solution**, not another embedded starter. The original project makes its value display editable. Keep that capability with a separate assignment action: `add` must continue to mean accumulation.

## Edit the setter and input

In `src/Store.ts`, add this method alongside `CounterStore.add` and `reset`:

```ts title="/Store.ts"
setValue(value: number) {
  if (Number.isFinite(value)) this.value = value;
}
```

`makeAutoObservable` infers the method as an action. In `src/App.tsx`, inside the observed `Counter`, replace only its value `output` with:

```tsx title="/App.tsx"
<input aria-label="Counter value" type="number" value={counter.value}
  onChange={event => {
    const value = event.currentTarget.valueAsNumber;
    if (Number.isFinite(value)) counter.setValue(value);
  }} />
```

The model owns this [controlled input](https://react.dev/reference/react-dom/components/input). Empty or invalid input is rejected, so it will not stay blank. An editor that permits intermediate text such as a minus sign needs a separate text draft and validation on commit. The existing computed total and browser effects read the same model value, so no extra synchronization is needed.

To keep the original display styling on the new input, extend the `.counter > output, .total > output` selector in `src/styles.css` to include `.counter > input`; retain its declarations.

## Check your work

With one counter, enter 42 and click +1: its value and total should become 43. Select the whole value and paste `-2.5`; the total should become `-2.5`. Clearing the field should leave the last finite value in the model. Continue with [inspecting the model](./14-inspect-model.mdx).
