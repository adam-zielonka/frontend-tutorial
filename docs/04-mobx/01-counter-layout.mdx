A counter needs a visible value and controls before it needs changing state. This new app already renders `Counter` with a zero. Its supplied stylesheet keeps the original yellow card, green display, blue buttons and Verdana type, adapted to a narrow preview.

## Edit the controls

In `/App.tsx`, replace the TODO below `output` with:

```tsx title="/App.tsx"
<div className="controls">
  <button type="button">-100</button>
  <button type="button">-1</button>
  <button type="button" aria-label="Reset">0</button>
  <button type="button">+1</button>
  <button type="button">+100</button>
</div>
```

`Counter` is a reusable [React component](https://react.dev/learn/your-first-component); `App` already renders it. `className="controls"` connects the markup to `/styles.css`. The `0` caption retains the original appearance, while its accessible name explains Reset. The buttons intentionally have no handlers yet.
