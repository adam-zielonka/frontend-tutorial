<summary>About this step</summary>

Start with the same counter layout as the original chapter: a displayed value and five controls. A small `Counter` function keeps this markup reusable. The starter already renders zero; complete its controls in `/App.tsx`. Styling is supplied in `/styles.css`.

There is no changing state yet, so the finished buttons are intentionally inert. Confirm the structure before adding behavior. This first step starts a new app; it does not contain the collection or persistence code from later lessons.
