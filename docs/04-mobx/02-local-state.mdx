This starter is the previous layout solution with a task comment added. No new model or dependency is needed: use React's `useState` to give each `Counter` its own value. Functional setter updates use the latest value when clicks are batched.

Make all five controls work. The sequence **+100 → -1** should display **99**; Reset should display zero. This local version establishes behavior that the MobX store will preserve in the next step.
