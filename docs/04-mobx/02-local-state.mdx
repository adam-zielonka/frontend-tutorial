The previous layout is complete, but its buttons do nothing. React's `useState` gives this `Counter` a value that survives renders; changing it asks React to render again.

## Edit the value and handlers

In `/App.tsx`, import `useState` from `react`. At the start of `Counter`, add:

```tsx title="/App.tsx"
const [value, setValue] = useState(0);
```

Replace the literal zero inside `output` with `{value}`. Then attach handlers to the existing buttons. For example:

```tsx title="/App.tsx"
<button type="button" onClick={() => setValue(current => current - 100)}>-100</button>
<button type="button" aria-label="Reset" onClick={() => setValue(0)}>0</button>
```

Apply the updater pattern to −1, +1 and +100 with their matching signs. `current` is the pending state, so queued updates accumulate. Reset directly supplies zero. Pass a function to `onClick`; calling the setter while rendering would update before a click. See [useState](https://react.dev/reference/react/useState) and [responding to events](https://react.dev/learn/responding-to-events).
