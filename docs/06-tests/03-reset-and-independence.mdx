The total in chapter 4 reads `store.sum`, a MobX computed property. A reset should change that total by exactly the value of the counter being reset. Use two different values so you can tell if the action accidentally resets both counters.

The first four cases are supplied. Replace the final `it.todo` in `/Store.test.ts`. Read the sum before and after resetting the first counter.

```ts title="/Store.test.ts"
it('resets one counter and updates the total', () => {
  const store = new Store();
  store.addCounter();
  const [first, second] = store.counters;
  first.add(7);
  second.add(-2);
  expect(store.sum).toBe(5);
  first.reset();
  expect(first.value).toBe(0);
  expect(second.value).toBe(-2);
  expect(store.sum).toBe(-2);
});
```
