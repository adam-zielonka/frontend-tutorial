<summary>About this step</summary>

The ordinary arithmetic tests do not prove the limits. A store that only handles small changes could still exceed capacity after a large delta.

In one new test, jump above 10, try another positive change, jump below zero, then try another negative change. Assert after **each** operation. These cases distinguish clamping from wrapping, ignoring an overshoot, or allowing a value outside the range.

The preview remains the same manual harness. Run `pnpm exec vitest run` against your edited export to execute the tests; the expected result is three passing and two pending cases.
