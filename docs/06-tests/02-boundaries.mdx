Small changes alone cannot prove that the store stays within its limits. Test both an overshoot and another attempt at each boundary; an assertion after each operation identifies where a failure occurs.

In `/Store.test.ts`, replace the clamping `it.todo` with:

```ts title="/Store.test.ts"
it('clamps large positive and negative changes to 10 and 0', () => {
  const store = new CounterStore();
  store.change(100);
  expect(store.value).toBe(10);
  store.change(1);
  expect(store.value).toBe(10);
  store.change(-100);
  expect(store.value).toBe(0);
  store.change(-1);
  expect(store.value).toBe(0);
});
```
