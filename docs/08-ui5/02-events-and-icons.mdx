Continue with the provider and button. UI5 button click handlers can request React state updates just like the native buttons in chapter 3. Add one `loaded` value and derive the displayed count from it.

Register `add` and `refresh` using their individual `.js` icon imports before using the names on the buttons. Keep the text labels so the icons supplement accessible names. Add Reset and check both actions with the keyboard.

This step establishes the actions; the ten-pallet capacity rule and progress display arrive next. For now use a few loads below capacity, then reset.
