<summary>About this step</summary>

The exercise pins UI5 Web Components for React and its matching packages to 2.15.0. They are already installed for the preview, independently from the documentation site's dependencies.

Start with composition: import `ThemeProvider` and `Button`, wrap the app, and replace the native button. The provider supplies UI5 React context. The button has no event handler yet; first check its label, rendering, and keyboard focus. Keep a single provider in `App.tsx`; do not add another in the generated entry point.
