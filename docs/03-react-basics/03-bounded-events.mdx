The starter already has state and Add pallet from the previous solution. Keep `count` as the single source of truth: the displayed number and button availability both follow it. [React events](https://react.dev/learn/responding-to-events) run handlers in response to interaction.

1. In `/App.tsx`, inside the `controls` div after Add pallet, insert:

   ```tsx
   <button disabled={count === 0}
     onClick={() => setCount(current => Math.max(0, current - 1))}>Remove pallet</button>
   ```

   `Math.max` clamps the update itself at zero; `disabled` communicates the boundary in the interface.
2. After that button add `<button onClick={() => setCount(0)}>Reset</button>`. Reset always sets zero, so it needs no previous value.
3. At zero Remove should be disabled. Add three, remove once, then reset: expect 3, 2, and 0. If Remove remains disabled after adding, check `count === 0` and ensure both buttons use the same state.
