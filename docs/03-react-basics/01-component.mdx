<summary>About this step</summary>

A React component is a function that returns JSX. JSX resembles HTML, but values such as `count` appear inside braces. This first counter is deliberately static: focus on the structure before adding events.

Keep one `main` root, add a labelled section, and use `output` for the displayed quantity. `aria-live="polite"` will help announce later updates. The preview already has an entry point supplied by the exercise, so edit only `App.tsx`. In an exported Vite project this file lives under `src/`.
