The starter contains the previous static component. A normal local variable is recreated on render; [React state](https://react.dev/reference/react/useState) preserves a value between renders and its setter requests an update.

1. At the top of `/App.tsx`, add `import { useState } from 'react';`. Inside `App`, replace `const count = 0;` with `const [count, setCount] = useState(0);`.
2. Inside the section, below the output paragraph, add:

   ```tsx
   <div className="controls">
     <button onClick={() => setCount(current => current + 1)}>Add pallet</button>
   </div>
   ```

   The outer function is the click handler; the inner updater receives the previous state, including queued updates. The existing output reads the new `count` on the next render.
3. Click Add pallet three times; expect 3. If it updates during rendering instead of on click, check that `onClick` receives a function rather than calling the setter directly.
