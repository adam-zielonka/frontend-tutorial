The previous component can display a value but cannot remember changes. `useState(0)` supplies both a value that persists between renders and a setter that requests another render.

Attach an event handler to Add pallet. The updater `current => current + 1` calculates the next count from the previous one, including when updates are queued. Calling the component again then renders the new value in the existing output.
